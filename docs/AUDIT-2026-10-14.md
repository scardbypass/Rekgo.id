- Tidak ada bukti migrasi MySQL, route execution, browser test, atau pembayaran QRIS GoPay sungguhan berhasil.

## Temuan kode yang harus ditindaklanjuti

1. `app/Services/GopayPayments.php`: perbandingan nominal provider memakai `(int)$providerAmount`. Nilai seperti `1000.99` berpotensi diperlakukan sebagai `1000`. Wajib validasi nominal rupiah eksak tanpa truncation dan uji regresi sebelum live.
2. `app/Http/Controllers/UserController.php`: `bank()` melakukan pembaruan status verifikasi dua kali; perlu dirapikan.
3. `app/Http/Controllers/UserController.php`: ketika bridge gagal membuat QRIS, record pending lokal dapat tertinggal tanpa `provider_ref`. Perlu status kegagalan yang aman dan reconciliation jika provider ternyata sudah membuat transaksi.
4. `app/Http/Controllers/AdminController.php`: penandaan WD success masih berdasarkan input referensi manual; tidak ada bukti bank transfer otomatis atau verifikasi bank inquiry.
5. `app/Http/Controllers/IntegrationAdminController.php`: bot WA masih berupa konfigurasi; pairing/QR real tidak tersedia.
6. `app/Services/GopayPayments.php`: skenario late settlement, concurrent cancellation, duplicate callback dan amount mismatch belum terbukti melalui integration test.

## Keputusan keselamatan

- Pertahankan `GOPAY_LIVE_VERIFIED=false` dan QRIS live OFF.
- Jangan gunakan sistem untuk menerima dana riil sampai SDK terlisensi, merchant sandbox, signature/credential verification, database, test cases dan compliance review tersedia.
- Jangan menyebut hasil audit sintaks sebagai keberhasilan test Laravel+MySQL atau GoPay nyata.

## Rencana pengujian pada mesin development

```bash
composer install
php artisan key:generate
php artisan migrate --env=testing
php artisan route:list
php artisan test
```

Untuk integration test GoPay, gunakan merchant sandbox/test credentials yang sah, uji create/status/cancel/expiry, nominal cocok/tidak cocok, duplicate settlement, retry, concurrent workers, late settlement dan ledger balance invariant. Jangan menggunakan dana sungguhan untuk uji awal.
