Dokumentasi RekGo

Referensi developer untuk website rekber, bot WhatsApp terpisah, API, instalasi VPS, dan alur order dari pendaftaran sampai pemeriksaan admin.

⚠️ Pengembangan / staging — belum siap transaksi dana nyata

01. Arsitektur sistem

🌐 Laravel

PHP 8.2+, Blade, akun, escrow, wallet, audit dan API.

🗄️ MySQL

Satu database sebagai sumber kebenaran bisnis.

🤖 Bot WhatsApp

Node.js, Baileys, PM2, plugin dan autentikasi API.

WhatsApp → Baileys → Bot (PM2) → Laravel API → MySQL
Browser → HTTPS → Nginx → Laravel ────────────┘

Bot tidak boleh memodifikasi saldo melalui SQL langsung. Semua validasi finansial berada di Laravel.

02. Daftar peran

Owner

Pengawasan dan pengaturan utama. Hak akses Owner khusus bot belum diterapkan.

Admin

Memeriksa transaksi, pembayaran, WD dan laporan.

Seller

Membuat grup WhatsApp dan draft order rekber.

Buyer

Tidak perlu akun. Membayar setelah instruksi sah dan meminta penyelesaian.

03. Alur order rekber

Hanya Seller yang mendaftar akun RekGo. Buyer tidak perlu membuat akun.
Seller membuat grup WhatsApp, memasukkan Buyer dan bot.
Seller mengirim /rekgo 10000; Laravel memvalidasi seller, fee, dan membuat escrow pending.
Buyer menunggu instruksi pembayaran resmi. Integrasi pembayaran live belum selesai.
Dana diverifikasi oleh proses pembayaran tepercaya sebelum escrow berstatus paid.
Setelah barang/jasa selesai, Buyer mengirim rekber done.
Admin memeriksa bukti. Permintaan selesai tidak otomatis mencairkan dana.
Pencairan, refund dan sengketa memerlukan proses serta pengujian tambahan.

Jam admin yang direncanakan: 09.00–20.00 WIB.

05. Instalasi website (Debian 12)

Siapkan Nginx, PHP 8.2+, Composer, MariaDB dan Node.js 20+. Arahkan DNS domain ke VPS.

sudo apt update
sudo apt install -y git unzip nginx mariadb-server composer php-cli php-fpm php-mysql php-mbstring php-xml php-curl php-zip php-bcmath
git clone https://github.com/scardbypass/Rekgo.id.git /rekgo
cd /rekgo
composer install --no-dev --optimize-autoloader
cp .env.example .env

Buat database MySQL kosong dan user khusus. Isi /rekgo/.env dengan URL, DB, dan API key bot.

APP_ENV=production
APP_DEBUG=false
APP_URL=https://rekgo.my.id
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_DATABASE=rekgo
DB_USERNAME=rekgo_app
DB_PASSWORD=GANTI_PASSWORD
REKGO_BOT_API_KEY=SECRET_ACAK_MINIMAL_32_KARAKTER
GOPAY_LIVE_VERIFIED=false
cd /rekgo
php artisan key:generate  # HANYA instalasi BARU
php artisan migrate --force
php artisan storage:link
php artisan optimize:clear

Konfigurasi Nginx dengan document root /rekgo/public, PHP-FPM dan HTTPS. Jalankan Laravel scheduler setiap menit bila diperlukan.

06. Instalasi bot & PM2

cd /rekgo/bot-rekgo
npm install
nano .env
REKGO_API_URL=https://rekgo.my.id
REKGO_BOT_API_KEY=SECRET_SAMA_DENGAN_LARAVEL
REKGO_AUTH_DIR=./auth
REKGO_BOT_CONTROL_PORT=4320
REKGO_PAIR_PHONE=
OWNER_NUMBER=62XXXXXXXXXXX
npm install -g pm2
node --check index.js
node --check plugins/commands.js
npm test
pm2 start ecosystem.config.js
pm2 save
pm2 startup
pm2 logs rekgo-bot --lines 50

Pairing WhatsApp belum terbukti berhasil. Error 405 perlu diperiksa pada Baileys/registrasi WA; PM2 saja tidak menyelesaikannya. Jangan menjalankan dua proses dengan folder auth yang sama.

07. Keamanan

Rahasia

Jangan unggah .env, OTP, token, password, atau sesi WhatsApp ke GitHub.

Keuangan

Verifikasi settlement, nominal, referensi, idempotensi dan audit sebelum mencairkan dana.

Upgrade

Backup database dan auth. Jangan mengganti APP_KEY pada instalasi lama tanpa rencana migrasi.
